# 전국 청소년 이동형 쉼터 최적 입지 및 순회 경로 선정 
## 제8회 한국코드페어 해커톤 출품작 마스터 기획안 (최종본 V2)

**작품명**: 신뢰할 수 있는 AI 기반 이동형 쉼터 실시간 입지·경로 최적화 웹 서비스  
**참가 분야**: 공간 데이터 분석 / 사회복지 / 청소년 정책  
**핵심 가치**: 신뢰할 수 있는 AI와 인간이 함께 만들어가는 안전하고 포용적인 미래 사회

## 1. 서론: 문제 정의 및 배경 (Problem Statement)

### 1.1 사교육 쏠림 현상과 청소년 쉼터의 공간적 미스매치
대한민국의 사교육 시장은 세계적인 규모이며, 2026년 현재 전국적으로 13만 개가 넘는 학원 및 교습소가 운영되고 있습니다. 방과 후부터 심야 시간까지, 수많은 청소년이 서울 강남, 인천 송도, 대구 수성 등 특정 학원 밀집 지역으로 매일 쏟아져 나옵니다. 

이들은 하루 평균 3~5시간 이상을 학원가나 길거리에서 보내지만, 잠시 심리적 안정을 취하거나 가출·폭력 등 위기 상황에서 긴급한 도움을 받을 수 있는 **'청소년 쉼터'**는 턱없이 부족합니다. 예를 들어 인천의 경우, 수만 개의 학원에 대응하는 쉼터는 전역에 단 8개소에 불과하며, 이마저도 학원가(수요처)와 멀리 떨어진 엉뚱한 외곽이나 구도심에 **'고정'**되어 있습니다.

### 1.2 기존 인프라의 한계와 새로운 제안
1. **정적(Static) 인프라의 한계**: 건물 형태의 고정형 쉼터는 시시각각 변하는 청소년의 유동 패턴과 방학/학기 중의 쏠림 현상을 유연하게 따라가지 못합니다.
2. **정책적 의사결정의 블랙박스**: 예산은 한정되어 있는데 '어디에', '어떤 기준'으로 복지 자원을 투입해야 하는지에 대한 객관적인 데이터 분석이나 투명한 AI 최적화 도구가 부재합니다.

> **제안 (Solution)**:  
> "단순히 감에 의존하는 배치를 넘어, 공공데이터와 AI 수학적 최적화 알고리즘을 융합하여 **'이동형 쉼터 차량(버스)'**의 최적 정차 거점(p-median)과 순회 경로(TSP)를 도출하고, 이를 정책 입안자가 실시간으로 조작·검증할 수 있는 **[서버리스 웹 대시보드]**를 제안합니다."

## 3. 공간 밀도 분석: CVI와 KDE (수학적 핫스팟 도출)

단순히 인구통계학적 숫자나 행정구역별 개수 합산만으로 쉼터 입지를 선정하면 심각한 오류가 발생합니다.

### 3.1 로지스틱 회귀(Logistic Regression) 기반 복합취약지수 (CVI) 산출
초기 분석에서는 학원수, 스트레스, 청소년 인구에 임의의 가중치를 부여했으나, 이는 '신뢰할 수 있는 AI'의 요건인 수학적 객관성이 결여되는 한계가 있었습니다. 
이를 극복하기 위해 **로지스틱 회귀분석**을 도입하여 데이터 기반의 타당한 가중치를 역산출하였습니다.

특정 지역의 실제 위기 청소년 발생 비율(종속변수 $Y$)에 미치는 영향을 독립변수로 학습시켰습니다.
$$\log\left(\frac{P(Y=1)}{1-P(Y=1)}\right) = \beta_0 + \beta_1 A + \beta_2 S + \beta_3 P$$

학습 결과, 각 변수의 회귀계수(Odds Ratio 기반 상대적 영향력)는 대략 **0.53 (학원 밀집도) : 0.30 (스트레스) : 0.17 (인구수)**의 비중으로 도출되었습니다. 
이를 정규화하여 최종 CVI 가중치로 확정했습니다.
- $w_A$ (0.53): 학원 분포 데이터 (유동 인구 및 사교육 체류 시간 반영)
- $w_S$ (0.30): 스트레스 인지율 (가출 등 위기 상황 촉발 위험도)
- $w_P$ (0.17): 청소년 주민등록 인구 (배후 시장 규모)

$$ \text{CVI}(i) = 0.53 \cdot \tilde{A}(i) + 0.30 \cdot \tilde{S}(i) + 0.17 \cdot \tilde{P}(i) $$
(여기서 $\tilde{X}$는 Min-Max 정규화된 지표)

### 3.2 KDE (Kernel Density Estimation) 적용과 MAUP 극복
행정구역(동/구 단위)을 기준으로 수치를 합산하면 경계선 근처의 밀집도가 분산되어 핫스팟을 놓치는 **MAUP(Modifiable Areal Unit Problem, 공간단위 수정의 문제)**에 빠지게 됩니다. 

본 프로젝트는 점(Point) 데이터인 학원 및 쉼터 좌표에 **가우시안 커널(Gaussian Kernel)**을 씌워 공간을 **연속적인 확률 밀도 함수(Density Surface)**로 변환했습니다. 
$$ \hat{f}(x) = \frac{1}{nh} \sum_{i=1}^{n} K\!\left(\frac{x - x_i}{h}\right) $$
이 수학적 평활화(Smoothing)를 통해, 행정동 경계에 갇히지 않고 **"청소년 수요는 가장 폭발하지만 기존 쉼터 인프라는 닿지 않는 극심한 복지 역전 핫스팟(Red Zone)"**을 시각적, 수학적으로 정확히 도출해 냈습니다.

## 4. 인공지능 입지 및 경로 최적화 알고리즘 (Optimization Phase)

발견된 핫스팟에 이동형 쉼터(차량)를 투입하기 위해 2단계의 최적화 파이프라인을 가동합니다.

### 4.1 Phase 1: 거점 도출 (p-median 모델과 형평성 파라미터 λ)
예산 한계로 $p$대의 쉼터 차량만 투입할 수 있을 때, 모든 청소년들의 차량 접근(이동) 총거리를 최소화하는 '최적 정차 거점(Hubs)'을 찾습니다. 
문제는 $p$-median 모델(NP-hard)로 정의되며, 이를 가중치가 적용된 **k-means 클러스터링 알고리즘**을 통해 근사 해를 도출합니다.

특히, 알고리즘을 블랙박스에 가두지 않고 정책 입안자가 **람다(λ, 형평성 계수)**를 직접 조절할 수 있도록 개방했습니다.
- `λ = 0`: 철저히 효율성 우선 (CVI와 인구가 쏠린 번화가에 집중 배치)
- `λ = 1`: 철저히 형평성 우선 (인구는 적더라도 거리가 멀리 떨어진 소외 외곽 지역을 포용)
이를 통해 AI가 내놓는 일방적 정답이 아닌, **"인간(정책 결정자)의 복지 철학과 결합하여 결과를 유연하게 내놓는 설명 가능한 AI"**를 구현했습니다.

### 4.2 Phase 2: 외판원 문제(TSP)를 활용한 차량 순회 최적화 (멘토링 반영)
p-median으로 최적 정차 거점(Hubs)을 찾아낸 후, 실제 **'이동형 쉼터 차량'이 이 흩어진 거점들을 어떻게 방문하며 순회(Patrol)할 것인가**를 외판원 문제(TSP, Traveling Salesperson Problem)로 모델링했습니다.

차량이 이동하는 이차원 유클리드 평면 공간은 거리에 대해 **삼각 부등식(Triangle Inequality, $d(x,y) \le d(x,z) + d(z,y)$)**이 성립하는 Metric TSP 환경입니다. 
따라서 본 프로젝트는 다항 시간 내에 최적 순회 정답의 1.5배 이내로 근사해를 수학적으로 무조건 보장하는 **크리스토피데스 알고리즘(Christofides Algorithm)**을 적용하였습니다. 

이로써 [핫스팟 발굴(KDE)] $\rightarrow$ [정차 거점 선정(p-median)] $\rightarrow$ [차량 순회 최적화(Christofides TSP)] 로 이어지는 완벽한 운영 알고리즘 파이프라인이 완성되었습니다.

## 5. 실시간 시각적 분석 웹앱 구현 (V2 Serverless Architecture)

위의 모든 복잡한 데이터 분석과 최적화 알고리즘을 논문에만 가두지 않고, 누구나 스마트폰과 PC에서 쉽게 접근하여 체감할 수 있도록 **100% 브라우저 기반 순수 JavaScript 정적 웹앱(PWA)**으로 아키텍처를 전면 개편(V2) 하였습니다.

### 5.1 Serverless 데이터 파이프라인 아키텍처
파이썬 서버 비용과 딜레이 문제를 해결하기 위해, 무거운 GeoPandas 연산과 로지스틱 회귀 학습은 오프라인 `export_data.py` 스크립트를 통해 사전에 완료하고 결과물만 가벼운 JSON으로 구웠습니다.
웹페이지는 GitHub Pages로 호스팅되며, 클라이언트 브라우저가 JSON을 넘겨받아 실시간으로 최적화를 수행합니다.

### 5.2 직관적인 V2 인터랙티브 UI 및 GPS 현장 기능
- **다크 글래스모피즘(Glassmorphism) 테마**: 사이버네틱하고 전문적인 데이터 분석 느낌을 주면서도 맵의 시야를 가리지 않도록 모든 컨트롤 패널을 좌측으로 밀착시켰습니다.
- **실시간 Visual Analytics**: 슬라이더를 당길 때마다 도보 30분 거리(2km 반경) 원형 커버리지가 지도에 그려지고, 핫스팟과 쉼터 차량 간의 **할당선(Spider Web)**이 거미줄처럼 펼쳐지며 커버리지 계산 결과(%)가 즉시 프로그레스 바에 표시됩니다.
- **현장 밀착형 내 위치(GPS) 추적 모달**: 단순히 정책 입안자용이 아닙니다. 우측 하단의 GPS 버튼을 누르면, 스마트폰의 실시간 위치를 추적하여 해당 동네의 복지 취약도(CVI 백분위)를 알려주고, **반경 10km 이내의 가장 가까운 쉼터 차량까지의 거리와 도보 시간을 모달 창으로 즉시 안내**합니다. (수동 주소 검색 API 포함)

## 6. 결론 및 기대 효과 (Conclusion & Impact)

본 프로젝트는 청소년 복지 정책의 해묵은 과제인 '쉼터 위치 선정' 문제를 공공데이터와 AI 최적화 기법으로 속 시원히 해결하는 실증적 모델입니다.

1. **예산 효율의 극대화**: 직관이 아닌 데이터를 기반으로 차량을 배치하므로 투입 예산 대비 청소년 보호 효과(Coverage)를 극대화할 수 있습니다.
2. **MAUP와 블랙박스 AI 극복**: KDE 밀도 분석을 통해 통계의 착시를 방지하고, 로지스틱 회귀를 통해 투명한 CVI 가중치를 부여했습니다.
3. **신뢰할 수 있는 포용적 복지**: 람다(λ) 파라미터 조작을 통해 소외 지역 계층까지 따뜻하게 보듬을 수 있는 철학을 인공지능에 탑재했습니다.

본 출품작은 데이터 엔지니어링, 공간 수학적 최적화(Voronoi, TSP), 그리고 뛰어난 프론트엔드 UI/UX가 한데 융합된 완성형 프로토타입입니다. 앞으로 네이버/카카오 실시간 API 교통량 데이터를 연동한다면, 내일 당장이라도 실제 지방자치단체 복지 현장에서 즉시 투입 가능한 혁신적인 사회적 가치 플랫폼이 될 것입니다.
