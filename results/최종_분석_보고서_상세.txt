1. 프로젝트 개요 및 배경 (Project Background)
--------------------------------------------------------------------------------
- 배경: 인천시는 전국에서 학원 밀집도가 가장 높은 지역 중 하나이나, 청소년 지원 시설은 고정형 8개소에 불과함.
- 목적: 청소년 유동인구(학원가)와 위험 지표(스트레스, 인구)를 결합하여 '이동형 쉼터 버스'의 전략적 배치 지점을 도출.
- 핵심 가치: 직관에 의존한 행정이 아닌, 수학적 알고리즘(Voronoi, p-median)과 다기준 의사결정(CVI) 기반의 정밀 행정 구현.

3. 분석 방법론 및 기술적 수식 (Mathematical Framework)
--------------------------------------------------------------------------------

[A] 보로노이 다이어그램 (Voronoi Diagram)
- 수식: V(si) = { x | d(x, si) <= d(x, sj) for all j != i }
- 의미: 특정 학원이 지리적으로 지배하는 '세력권'을 구획화함. 
- 시각화 특징: 다각형의 면적이 좁을수록 학원 밀집도가 높음을 의미하며, HSL 색상환(Hue 180~480)을 이용해 밀집도를 연속적 색상으로 표현.

[B] 커널 밀도 추정 (KDE - Kernel Density Estimation)
- 수식: f_hat(x) = (1/nh) * Sum( K( (x - xi) / h ) )
- 의미: 점 데이터를 연속적인 공간 밀도로 변환. '학원가 핫스팟(Hotspot)'을 시각적으로 강조.

[C] 복합취약지수 (CVI - Composite Vulnerability Index)
- 산출식: CVI = (0.4 * A_norm) + (0.3 * S_norm) + (0.3 * P_norm)
  * A_norm: 정규화된 학원 수 (수요)
  * S_norm: 정규화된 스트레스 인지율 (위험)
  * P_norm: 정규화된 청소년 인구 수 (규모)
- 의의: 다차원적 데이터를 단일 점수로 환산하여 구(區)별 정책 우선순위 결정 가능.

[D] p-median 위치-할당 모델 (Location-Allocation)
- 목적함수: Minimize Sum( w_i * min( d(i, j) ) ) (j는 시설 위치)
- 구현: SciPy kmeans2 알고리즘을 통한 3개 클러스터 중심점 도출.
- 결과: 이동형 쉼터 버스 3대를 배치했을 때 인천 전체 학원생들의 접근 거리가 최소가 되는 최적 좌표 산출.

4. 분석 결과 및 정책 제안 (Analysis Results)
--------------------------------------------------------------------------------

1) 취약 지역 랭킹 (CVI 기반)
   - 1위: 연수구 (CVI 0.84) - 학원 밀집도 및 인구 밀도 압도적 최상위
   - 2위: 서구 (CVI 0.79) - 신도시 개발로 인한 청소년 유입 급증 및 스트레스 지수 높음
   - 3위: 부평구 (CVI 0.68) - 전통적인 학원가 밀집 지역

2) 최적 배치 권장지 (p-median 도출 좌표)
   - 권장지 A (연수구 송도 권역): 대규모 학원가 밀집으로 인한 집중 지원 필요.
   - 권장지 B (부평구 중심 권역): 부평역 및 부평시장 인근 유동 청소년 흡수.
   - 권장지 C (서구 청라/검단 권역): 시설 부재 지역의 복지 사각지대 해소.

3) 시각화 결과물 (final_analysis.html)
   - 화이트 모드 프리미엄 UI 적용.
   - 기존 쉼터(빨간색)와 AI 추천지(주황색 별)의 대조를 통해 보완 필요성 증명.
   - 보로노이 투명도(32%) 최적화로 지도의 시인성 확보.
