[중간 보고서: 인천광역시 청소년 쉼터 입지 최적화 분석 현황]

1. 데이터 통합 및 정제 결과
   - 인천광역시 10개 군·구별 학원 데이터 통합 완료 (총 62,476건)
   - 데이터 필드 표준화: 학원명, 도로명 주소, 교습과정, 소속 지역구 정보 추출
   - 데이터 무결성 검토: 결측치 제거 및 중복 데이터(동일 학원 내 다수 교습과정) 확인 완료

2. 추가 분석 데이터셋 확보 현황
   - 청소년 쉼터 인프라: 전국 청소년 쉼터 현황 데이터(SHP, XLSX) 확보 및 인천 지역 데이터 필터링 완료
   - 수요 분석 데이터: 2026년 4월 기준 인천광역시 구별 청소년(아동/청소년/청년) 인구 통계 확보
   - 유동인구 지표: 인천광역시 정류장별 이용객 현황(2026.04.30 기준) 데이터 확보 (입지 최적화 모델의 가중치로 활용 예정)

3. 기술적 검토 사항
   - 공간 좌표계 확인: 쉼터 SHP 데이터의 좌표계가 EPSG:5186(중부원점)임을 확인, 분석 시 WGS84(위경도)와 호환 처리 예정
   - 인코딩 최적화: 공공데이터 특유의 인코딩(CP949, UTF-8) 문제를 해결하여 데이터 로드 프로세스 안정화
   - 분석 도구 환경: Python(Pandas, GeoPandas, Folium, Geopy) 기반 공간 분석 환경 구축 완료

4. 향후 분석 모델 적용 계획
   - 지오코딩(Geocoding): 통합 학원 데이터의 주소 정보를 위도/경도 좌표로 변환 작업 착수
   - KDE(커널 밀도 분석): 학원 밀집 지역과 기존 쉼터 위치를 비교하여 '복지 역전 지점' 도출
   - p-메디안 알고리즘: 버스 정류장 유동인구와 학원 수요를 결합하여 최적의 이동식 쉼터 버스 정차 위치 계산
   - 시범 분석: 학원 밀집도가 높은 '연수구(송도 포함)' 또는 '부평/남동구'를 대상으로 우선 모델링 실시 예정
