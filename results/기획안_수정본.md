# [제8회 한국코드페어 해커톤] 수정 기획안 — 초기 작품 대비 개선 사항

**주제**: 신뢰할 수 있는 AI와 인간이 함께 만들어가는 안전하고 포용적인 미래 사회
**작품명**: 청소년 쉼터 접근성 조회 및 최적 입지 선정 서비스 (V2)

---

## 1. 개요 및 배경

본 문서는 초기 작품(전국 청소년 이동형 쉼터 최적 입지 선정 모델)에서 **어떤 한계를 인식하고, 이를 어떻게 기술적으로 해결하여(V2 마이그레이션) 출품작을 고도화했는지**를 정리한 수정 기획안입니다. 기존의 복합취약지수(CVI) 모델링 산출물과 가치는 유지하되, **접근성(Accessibility)과 사용성(Usability), 그리고 시각적 증명(Visual Analytics)** 측면을 획기적으로 개선했습니다.

---

## 2. 초기 작품의 한계점

1. **블랙박스형 결과 도출 및 근거 부족**
   - 기존 모델은 CVI 가중치(40/30/30)가 고정되어 있었고, 효율성과 형평성 중 어느 것에 중점을 둘지 정책 입안자(사용자)가 결정할 수 없는 블랙박스 구조였습니다.
2. **무거운 서버 아키텍처와 접근성 결여**
   - Python(Flask 등) 서버 기반으로 설계되어 로컬 의존성이 컸으며, 심사위원이나 대중이 손쉽게 웹에서 결과를 열람하고 조작해 볼 수 없었습니다.
3. **단순한 렌더링 방식**
   - 시각화가 단순히 마커만 찍는 수준에 그쳐, 도출된 입지가 실제로 어떤 지역을 얼마나 커버(Cover)하는지 파악하기 어려웠습니다.

---

## 3. V2 주요 수정 및 개선 사항 (해결책)

이러한 문제를 해결하기 위해, 백엔드 서버를 완전히 폐기하고 **100% 브라우저 기반 순수 JavaScript 정적 웹앱**으로 아키텍처를 전면 마이그레이션 하였습니다.

### 3.1. 사용자 주도형 실시간 최적화 엔진 탑재
- **형평성-효율성(λ) 파라미터 개방**: 기존의 고정된 입지 선정 방식에서 벗어나, 사용자가 슬라이더를 통해 직접 람다(λ) 값을 0.0부터 1.0까지 조작할 수 있게 만들었습니다.
  - `λ = 0`: 인구 밀집 지역 최우선 (효율성)
  - `λ = 1`: 소외된 외곽 및 취약계층 지역 최우선 (형평성)
- **실시간 K-means & P-median 연산**: Python 서버에서 30초 이상 걸리던 무거운 Voronoi 연산을 사전 전처리(export_data.py)하여 데이터 경량화(GeoJSON) 하였습니다. 이를 통해 브라우저 단에서 1초 만에 실시간으로 최적 입지를 재계산합니다.

### 3.2. 웹 접근성 극대화 (Serverless Architecture)
- **GitHub Pages 연동**: 별도의 서버 구동 없이 누구나 접속 가능한 [Live Demo 웹 서비스](https://dohye0508.github.io/focus-hub-voronoi/) 형태로 개선했습니다. 모바일과 데스크톱 모두 반응형으로 동작합니다.

### 3.3. 전문적인 시각적 분석 효과 (Visual Analytics) 도입
- **할당선 (Spider Web Assignment)**: 각 생활권(Cell)이 어느 쉼터의 커버를 받는지 반투명한 선으로 연결하여 네트워크를 시각화했습니다.
- **2km 도보 커버리지 반경**: 도보 30분 거리(2km) 원을 그려 쉼터 사각지대가 해소되는 과정을 직접 눈으로 확인할 수 있게 했습니다.
- **다크 글래스모피즘(Glassmorphism) UI**: 화면의 중심(지도) 시야를 방해하지 않도록 컨트롤 패널을 좌측으로 정렬시키고 반투명 효과를 넣어 시각적 몰입감을 극대화했습니다.

### 3.4. 내 위치 기반(GPS) 실시간 분석
- **현장 밀착형 기능**: 우측 하단 GPS 버튼을 통해 사용자의 실시간 위치를 추적, 해당 위치의 CVI(위험도)와 가장 가까운 쉼터까지의 거리를 분석해 주는 기능을 추가하여 **"정책 입안자뿐만 아니라 실제 청소년도 사용할 수 있는 서비스"**로 확장했습니다. (수동 주소 검색 기능 포함)

---

## 4. 기대 효과

본 출품작(V2)은 AI 최적화 알고리즘의 결과를 단순히 보여주는 것에 그치지 않습니다. 정책 입안자는 이 서비스를 통해 **가용 예산(P개)**과 **복지 철학(λ값)**을 조율해 보며, 즉각적으로 최적의 쉼터 위치와 커버리지 상승(%)을 시뮬레이션할 수 있습니다. 

이는 **"신뢰할 수 있는 AI(설명 가능하고 조작 가능한 AI)"**를 활용해 인간과 AI가 함께 **안전하고 포용적인 미래 복지 사회**를 그려나가는 한국코드페어 해커톤의 기획 의도에 완벽히 부합합니다.
