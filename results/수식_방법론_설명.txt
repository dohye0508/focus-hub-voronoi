========================================================
분석 방법론 및 수식 상세 설명
인천 청소년 이동형 쉼터 최적 입지 선정 프로젝트
========================================================

1. 보로노이 다이어그램 (Voronoi Diagram)
──────────────────────────────────────────
학원 위치 집합 S = {s₁, s₂, ..., sₙ} 에 대해,
각 학원 sᵢ의 보로노이 세력권 V(sᵢ)는 다음과 같이 정의됩니다.

  V(sᵢ) = { x ∈ ℝ² | d(x, sᵢ) ≤ d(x, sⱼ), ∀j ≠ i }

  여기서 d(·)는 유클리드 거리 함수.

[해석] 각 다각형은 해당 학원이 다른 어느 학원보다 가장 가까운 지리적 영역,
즉 '수요 세력권'을 나타냅니다. 다각형이 좁고 촘촘할수록 해당 지역의
학원 밀집도가 높아 청소년 수요가 집중되어 있음을 의미합니다.

[색상 해석] 색상은 HSL 컬러 공간에서 밀집도 순위(rank)에 따라 부여됩니다.
  hue(i) = (180 + (rank(i) / N) × 300) mod 360
  saturation(i) = 0.72 + dn(i) × 0.20
  lightness(i) = 0.52 - dn(i) × 0.10
  dn(i) = (density(i) - min) / (max - min)

파란계열→보라→주황→빨강 순으로 밀집도가 높아짐을 나타냅니다.


2. p-median 알고리즘 (이동형 쉼터 배치 권장지 도출)
──────────────────────────────────────────────────────
이동형 쉼터 p=3대를 배치할 최적 위치를 구하기 위해
k-means 기반 p-median 근사 알고리즘을 사용합니다.

목적함수:
  minimize Σᵢ min_{j∈F} d(demandᵢ, facilityⱼ) × wᵢ

  F: 쉼터 배치 후보 집합 (|F| = 3)
  wᵢ: i번 수요점의 가중치 (모든 학원 위치를 균등 가중)

[적용] scipy.cluster.vq.kmeans2 알고리즘으로 학원 밀집 좌표 606개를
3개의 클러스터로 분리하여, 각 클러스터의 중심점(centroid)을
이동형 쉼터 배치 권장 위치로 제안합니다.

[의미] 이 3개 지점에 쉼터 버스를 배치하면 인천 전체 학원생들의
총 이동 거리 합계가 이론적으로 최소화됩니다.


3. 복합취약지수 CVI (Composite Vulnerability Index)
──────────────────────────────────────────────────────
단일 지표가 아닌 다중 요소를 통합하여 각 구(區)의 청소년 복지
취약도를 0~1 사이의 단일 점수로 정량화합니다.

  CVI(d) = 0.4 × A_norm(d) + 0.3 × S_norm(d) + 0.3 × P_norm(d)

  A_norm(d) = 학원수(d) / max(학원수)          ← 수요 지표 (가중치 40%)
  S_norm(d) = 스트레스인지율(d) / max(스트레스)  ← 위험도 지표 (가중치 30%)
  P_norm(d) = 청소년인구(d) / max(청소년인구)    ← 규모 지표 (가중치 30%)

[데이터 출처]
  - A: 나이스(NICE) 인천시 학원 등록 데이터 (2026.05 기준, 62,476건)
  - S: 통계청 시군구별 스트레스 인지율 (2025년도)
  - P: 행정안전부 주민등록 인구통계 (2026.04 기준, 10~24세 합산)

[예시 해석] CVI가 0.80인 구는:
  학원 밀집도, 청소년 스트레스, 청소년 인구 세 지표 모두에서
  인천 평균 대비 높은 수준이므로 이동형 쉼터 배치의 최우선 대상지.


4. 커널 밀도 추정 (KDE, Kernel Density Estimation)
──────────────────────────────────────────────────────
학원 위치를 점(point) 데이터로 보고, 연속적인 밀도 분포 함수를 추정합니다.

  f̂(x) = (1/nh) Σᵢ K((x - xᵢ)/h)

  n: 학원 수, h: 대역폭(bandwidth), K: 가우시안 커널 함수

[적용] folium HeatMap (radius=20, blur=16) 형태로 시각화.
색상이 빨간색에 가까울수록 단위 면적당 학원 수가 많음을 의미합니다.

[대역폭 h의 의미]
  h가 작을수록 개별 학원 위치를 세밀하게 표현하고,
  h가 클수록 광역 밀집 패턴이 부각됩니다.

6. 분석의 흐름 (논리 구조)
──────────────────────────────────────────────────────
현황 파악 (보로노이)
  → "학원 세력권 분석 결과, 복지 시설이 없는 구역이 광범위합니다"

심화 분석 (KDE + CVI)
  → "그 중에서도 학원 밀도·스트레스·청소년 인구가 동시에 높은
     '복합취약 지역'이 연수구, 부평구에 집중되어 있습니다"

최적 대안 제시 (p-median)
  → "이 수요지를 커버하기 위해 이동형 쉼터 3대의 최적 배치 위치를
     수학적으로 산출한 결과, 해당 지점들이 도출되었습니다"
